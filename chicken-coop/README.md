# 鶏小屋 建築プロジェクト

兵庫県三田市乙原。既存の基礎（地中ブロック＋木の土台）の上に建てる4羽用の鶏小屋。
幅190 × 奥行100 × 室内高167（cm）／片流れ屋根／自動扉つき。

## いま止まっているところ

**アンカーボルトのねじ山の余りを測る。**
土台とブロックの間に縁切り層が入っておらず、骨組みを載せる前の今しか直せない。
余りが20mm以上あれば気密パッキン、無ければブチルテープ。詳細は HANDOFF.md の 5.1。
