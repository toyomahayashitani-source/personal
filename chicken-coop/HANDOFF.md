## 1. 概要

既存の基礎（地中に埋めたコンクリートブロック＋その上に固定した木の土台）の上に建てる、
4羽用の鶏小屋。日中は庭に放し飼いにするため、小屋は**寝床と産室**と割り切った設計。

| 項目 | 値 |
|---|---|
| 外形 | 幅190 × 奥行100 |
| 室内有効高 | 前167 / 後150 |
| 室内床面積 | 約1.41㎡（172×82） |
| 屋根 | 片流れ・奥下がり・約2.1寸勾配 |
| 全高 | 約195cm（GLから） |
| 飼育羽数 | 4羽 |
| 床 | 土のまま |
| 単位 | cm（材の断面のみmm） |

**高さの基準**

- `GL` = 地面
- `FL` = 土台上端 = GL+15（既存基礎の出っ張り）
- 図面中の高さは断りがなければ **FL基準**

**産卵箱を浮かせる理由**: 床面積を食わず、箱の下が鶏の隠れ場所になる。

### 2.4 産卵箱（ロールアウト式）

床を傾けて、産んだ卵を正面壁側の受け皿へ転がり落とす方式。鶏が卵に触れられないので、
**卵が汚れず、つつき割りと食卵癖が起きない**。

| 項目 | 値 |
|---|---|
| 内寸 | 30W × 40D × 高30（高い側で） |
| 外寸 | 32.4 × 40 × 高39.4 |
| 産卵エリア | 奥行30（傾斜床） |
| 受け皿 | 奥行10 × 幅30 |
| 床の傾斜 | **落差4／奥行30 ＝ 約7.6°** |

**高さの通し**

| 部位 | 高さ |
|---|---|
| 受け桟（O）天端 | FL+31 |
| 受け皿の底（内側） | FL+32 |
| 傾斜床・壁側（低） | FL+35 |
| 傾斜床・室内側（高） | FL+39 |
| 受け皿カバー（T）下面 | **FL+41**（卵の通り道は隙間6cm） |
| 入口の縁（M）天端 | FL+44 |
| 天板 下面 | FL+69 |
| 止まり木（参考） | FL+85 |

**外せない4点**

1. **傾斜は7〜10°の範囲。** 落差4cm／奥行30cmで約7.6°。緩いと転がらず、急だと鶏が使わない
2. **敷料は入れない。** 入れた時点で卵が止まる。代わりに**人工芝マット**を傾斜床に敷く。
   傾いた裸の合板には鶏は産まない——ロールアウト式が失敗するときの原因はほぼこれ
3. **受け皿カバー（T）は必須。** 無いと鶏が受け皿に降りて卵をつつき、糞をする。
   傾斜床の端との隙間は6cm——卵は通るが鶏は入れない
4. **受け皿の底に緩衝材。** 合板に直接当たると卵が割れる

**慣らし期間**: 産み始めだけは傾斜床の上に**水平な板を仮置き**し、敷料と偽卵を入れて
普通の産卵箱として使わせる。ここで産むと覚えてから外す。
最初からロールアウトにすると産む場所が分からず床で産み始める。

## 5. 次にやること（優先順）

### 5.1 【最優先】アンカーボルトのねじ山の余りを確認する

土台とブロックの間に**縁切り層が入っていない**。ブロックが地中から吸い上げる水が
直接木に渡っており、しかも土台には**シリコン系（造膜型）の塗料**が塗ってあるため
水の逃げ道がない。放置すると土台が下から腐る。

**骨組みを載せる前の今しか直せない。**土台は外せることを確認済み。

判断基準は1点だけ:

| ボルトの余り | 採用する材 | 費用 |
|---|---|---|
| **20mm以上ある** | 城東テクノ **気密パッキンロング KPK-N105**（105×908×20mm）× 7本 | 約¥5,800 |
| **余りが無い** | **ブチル防水テープ（片面・幅100mm）** 20m巻 | 約¥2,500 |

- **品番の「KPK」が気密、「KP-L」は通気。** 通気タイプは20mmのスリットが
  外と室内を床上8〜15cmで直結させ、冬に足元を隙間風が吹き抜けるので**不可**。
- 土台の幅も測ること（90角なら105mm用で足りる）。
- 気密パッキンは20mm持ち上がるので、ボルトに余裕が無ければ物理的に使えない。
- ブチルテープは片面を選ぶ（両面だと位置決めのやり直しと将来の交換ができない）。
- 販売: ソニテック https://www.sonitech.jp/items/3893 ／ コーナン（ブチルテープは在庫あり）

### 5.2 土台を外して縁切りを入れる

1. ブロック天端の埃と水気を落とす（ブチルは汚れていると付かない）
2. テープ／パッキンを敷く。継ぎ目は5cm重ねる（突きつけない）
3. **外している間に土台の木口を塗る**（底面は塞がるので不要）
4. ブロックの空洞に水が溜まっていないか、天端が平らかを確認
5. 土台を戻す

### 5.3 木材を購入

ロイヤルHC三田に在庫・カット・配達を確認。**柱だけは実測してから切る**
（既存土台の高さがどこも15cmとは限らないため）。垂木と波板は図面どおりで可。

### 5.4 全部材を切ってから塗装、乾かす

組んでから塗ると木口・接合部・裏面が塗れない。
- 柱の**下側の木口**をたっぷり
- 合板は**木口を最優先で2〜3回、そのうえで表裏の両面**（片面だけだと反る）
- 完全に乾かしてから組む

### 5.5 以降の組立順

1. 土台の水平・直角を測り直す（対角214.7cm）
2. 前面フレームを地面で組んで立てる
3. 背面フレームも同様
4. 側面つなぎ(E)・中段材(F/G)を入れる ← ここで構造が固まる
5. 垂木6本（前に10、後ろに8出す／ピッチ約37）
6. 波板を**高い側＝手前から**張る
7. 受け桟(O)をFL+31に渡して産卵箱を据える → 傾斜床(R)を落差4で入れ、人工芝マットを敷き、受け皿カバー(T)を下面FL+41で渡す
8. 集卵扉を付ける
9. 自動扉(T50)を取り付けて開閉テスト
10. 板張り → 金網
11. 人用の扉（枠が固まってから実測し、−5mmで作る）

## 6. 施工上の要点（間違えやすい点）

### 接合部

| 箇所 | 方法 |
|---|---|
| 柱 → 桁 | 桁の上から**90mmビス2本をハの字に**＋**柱の外面に山形プレート1枚** |
| 垂木 → 桁 | **斜めビス65mm×2 ＋ ひねり金物1個**／各交点（計12箇所） |
| 柱脚 | L金物を隣り合う2面に＋65mmビス |
| 合板 | 41mmビス／外周@150・中通り@250／端から15mm内側 |

- **木口へのビスは保持力が半分以下。** 柱天端は必ず金物を併用する。屋根は風で持ち上がる。
- **垂木のビスは必ず斜めに。** 勾配が緩く接点が「線」なので、垂直に打つと隙間を貫通するだけ。

### 合板

- **必ず現物合わせで切る。** 図面の数字で先に切らない。組んだ枠は必ずどこか狂っている。
- **重ねない（鎧張りにしない）。** 平らに突きつける。鎧張りは杉の無垢板を使う場合の工法。
- **目地は必ず下地の上で、2〜3mm空けて突きつける。** ぴったりだと雨で膨らんで浮く。
- 下地が無い位置に目地が来るなら、**45×45の目地受け**を1本入れてから張る。
- **横目地の上には押し縁**（15×30）を1本。突きつけたままだと水が入る。
- **出隅は4隅に隅木**（15×30）。どう張っても片方の木口が外に出る。
- **合板の下端は土台より10〜15mm下げる。** 土台上面で切り揃えると水が溜まって両方腐る。
- ビスは締めすぎない（皿頭が面一〜0.5mm沈む程度）。

### 塗装

- **浸透型を使う。** 造膜型（ウレタン系ペンキ）は木口から入った水の逃げ場がなくなり、
  内部から腐って一気に剥離する。
- **合板は「特類」でも撥水しない。** 特類が意味するのは接着剤が剥がれないことだけ。
  構造用合板は本来、外装材で覆われる前提の下地材。
- 内側と産卵箱の中は柿渋・ウッドロングエコなど鶏に安全なものを。
  ただし**片面塗装は反る**ので、薄くても両面に何か塗る。

### 金網

- **目合10mm・亜鉛引亀甲金網を1重で。** 10mmならネズミも通れず、
  **獣が指や爪を掛けられない**ので2重にする必要が消える。
- **ステープルで留めない。押さえ縁で挟んでビス留め。**
  獣は網ではなく**縁を引き剥がしにくる**。ビスは合板ではなく柱・中段材に効かせる。
- **切り口は1cmほど内側へ折り返す。** 線の端が跳ねて鶏を傷つける。
- 切り口にジンクリッチペイント（ローバル等）を一塗りすると弱点の大半が消える。
- 必要量4.89m ／ 5m巻に対し余裕は11cm。**大きい面から切り、スカートを最後に回す。**
  足りなければスカートの帯を30→22cmに詰めると4本取りになって48cm浮く。

### 屋根

- 波板は**必ず高い側＝手前から**張る（低い側から張ると重ねが逆になり雨が入る）。
- 重ねは2.5山以上、ビスは山の頂点に5山おき。下穴を開けるとポリカが割れない。
- 屋根の水は全部**奥に落ちる**。奥に50cm以上の余裕か雨樋を。

## 7. 設計判断の記録（なぜそうしたか）

後から「改善」して元の失敗に戻さないための記録。

### 高さ167は「室内有効高」

土台上端から桁の下端までを167とした。地面からの全高は約195cmになる。
「かがまずに入れる」が基準という指示による。

### 奥行を70→100に変更

床面積が1.0→1.41㎡になり、4羽で1羽あたり0.35㎡。
止まり木を後ろの壁から30cm以上離せるようになり（尾羽が擦れない）、
糞受けトレーの空間もできた。勾配2.1寸を維持したまま、
**屋根の水平長を118cmにすることで波板4尺がぴったり収まる**関係も保てている。

|---|---|---|---|
| 溶接金網ファインメッシュ13.8mm | 約¥8,800 | 1重 | 約¥39,000 |
| 亀甲16mm | ¥940 | 2重 | ¥8,560 |
| **亀甲10mm** | ¥1,314 | **1重** | **¥5,980** |

溶接金網は工業用フィルターの流通で、**目を粗くしても値段が下がらない**（面積課金）。
一方10mmの亀甲なら1重で足り、目詰まりも起きにくい（開口率85%、16mmの88%とほぼ同じ）。
**5mm目は開口率74%まで落ち、鶏の粉じんと羽毛で塞がる**ので不採用。

### 産卵箱を外付け→室内に変更

正面の35cmの出っ張りが消え、独立した屋根も方杖も不要になり、
箱が室内にあるぶん冬は暖かい。FL+35に浮かせたので床面積も食わない。

### 産卵箱の内寸を38×35→30角に変更

中型の卵用種（ボリスブラウン、さくら、もみじ等）の標準は**30×30×高30**。
38×35は標準より広く、**2羽が同時に入って卵を割る**、**寝床にされて糞まみれになる**
という失敗が起きる寸法だった。

産卵箱は広いほど良い設備ではない。狭くて暗いほど鶏が落ち着いて産む。
30角は「最低限」ではなく、この用途では**上限に近いちょうどいい値**。

連動して集卵扉が44×38→32×28、壁の開口が40×28→28×24に縮む。
正面左ベイ（内寸81.5）の余裕は11.5→19cmに増えるので、他の寸法への影響はない。

> **この寸法は次項で更新済み。** ロールアウト式にしたため奥行は40に戻し、
> 集卵扉は32×13、開口は28×9になった。幅30は変わっていない。

### ロールアウト式を採用（奥行は30→40に戻した）

30角に決めた直後の変更。**卵が汚れず、つつき割りと食卵癖が起きない**ことを優先した。
食卵は一度覚えると群れに伝染して止まらないので、その保険。

**幅30はそのまま、奥行だけ40に戻した。**受け皿が奥行10を食うため、
30角のままだと産卵エリアが20cmしか残らず中型鶏には狭すぎる。
市販のロールアウト式が30W×40Dなのはこの理由。産卵エリアは30×30で標準どおり。

引き換えに増える手間: 傾斜床・受け皿カバー・人工芝マット・緩衝材。
引き換えに失うもの: 敷料が使えない（入れると転がらない）。

**鶏が使わないリスクがある。**扉式にこのリスクは無い。人工芝マットと慣らし期間（2.4）で
対処するが、それでも床で産み続けるようなら傾斜床を外して水平に戻せば扉式に戻せる。
そのために受け皿とカバーは**ビス留め（接着しない）**にしておくこと。

### 合板を選択（杉板の鎧張りは不採用）

杉板の下見板張り（鎧張り）も検討したが、重ね代のぶん必要量が3割増え、
さらに面材効果が無いので**筋交いを4本追加**する必要があり、合板の2倍以上かかる。
合板が入手できたため不採用。**合板は重ねずに平らに突きつける。**

### 電気柵は不採用

電気柵は「毛の少ない鼻」に電線の高さを合わせて効かせる道具。
イノシシ・シカには有効だが、**イタチは体幅4〜5cmで線の間をすり抜け、木を登って上から来る。**
小動物用でも4段張りで線間10〜15cmあり、止められない。
止めるのは金網の仕事。なお設置には**危険表示の掲示義務**と、
電気用品安全法の適用を受けた電源装置の使用が必要。

### 給餌器・給水器は室内に吊る

床置きは敷料を蹴り込まれ糞も入る。縁を鶏の背の高さ（FL+45〜50）に合わせて吊る。
**水は必ずニップル式。** 皿式は必ずこぼれ、濡れた敷料はアンモニアと
コクシジウムの温床になる。

### 日中の放し飼い時間は短縮しない

被害の大半は**夜**、次いで**朝夕の薄明**に起きる。昼は最も安全な時間帯なので削っても得が少ない。
一方、1.41㎡に4羽を終日閉じ込めると**つつき合い**と、砂浴びができないことによる
**ワクモ・トリサシダニの増殖**が起きる。こちらの方が発生確率が高い。
時間を絞るなら、**自動扉の朝の開扉を日の出+30〜60分に遅らせる**方が的確。

## 8. 飼育の前提と運用

- **4羽・土の床・日中は庭に放し飼い**（庭は全体が囲われている）
- 産卵箱は3〜4羽に1室が目安なので**1室でよい**（空きがあっても全羽が同じ1室に入りたがり、順番待ちする）
- 産み始めるまで**陶器の偽卵を1個**置く。ここが産む場所だと教えるのに一番早い。床で産み始めたらその卵をすぐ箱に移す（癖がつくと直りにくい）。
  ただし**ロールアウトでは偽卵も転がる**ので、慣らし期間は2.4のとおり傾斜を殺して使う
- **産卵箱に敷料は入れない**（ロールアウト式のため）。入れると卵が転がらない。傾斜床には人工芝マットを敷く。
  床（土のまま）に敷く敷料とは別の話なので混同しないこと
- 止まり木は1羽25cmで足りる（170cm確保）
- 通気帯は背面・側面の上端25cm。鶏は寒さより**湿気とアンモニア**に弱いので冬も塞ぎ切らない

### 運用の要点

- **夕方の点呼。** 自動扉は時間で閉まる。1羽外に残ると朝にはいない。
- **夜に餌を外に残さない。** 残飼料がネズミを呼び、ネズミがイタチとテンを呼ぶ。
- **殺鼠剤は絶対に使わない。** 毒を食べたネズミはふらついて出てきて、鶏がそれを食べる。
  二次中毒で鶏が死ぬ。対策は餌の管理と、鶏が触れない密閉箱に入れた物理トラップのみ。
- **庭に隠れ場所を作る。** 低木や物陰があると猛禽・カラスから自分で隠れる。
- 品種によっては塀を越える。越えるようなら**片翼だけ**風切羽を切る。

### 立地条件（三田市乙原）

- **海から30km以上の内陸**。飛来塩分が無く ISO 9223 の C2（田園）にあたる。
  亜鉛の減りは年0.4μm程度で、線径0.85mmの亀甲金網ならメッキだけで10〜20年。
  **ステンレスに投資する理由はない。**
- **多雪区域ではない。** 垂木のスパンが82cmに伸びたが45×45のままで問題ない
  （積雪30cmで曲げ応力1.8N/mm²・たわみ0.8mm、杉の許容6.4に対し余裕あり）。
  50cm超の積雪が毎年あるなら60×45にするか中間に母屋を1本。
