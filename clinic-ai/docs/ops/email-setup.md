# メール環境の構成案(未着手・検討段階)

屋号「北摂AIサービス」名義の問い合わせ窓口をどう作るか。あわせて、Claude Codeから送受信を扱えるようにする構成。

## 推奨構成: 独自ドメイン + Gmail + Gmail API

1. ドメイン取得(例 `hokusetsu-ai.com`、年1,500円前後)
2. **Cloudflare Email Routing**(無料) https://www.cloudflare.com/ja-jp/developer-platform/products/email-routing/
   で `info@hokusetsu-ai.com` 宛のメールを既存のGmailに転送
3. Gmail側で「エイリアスとして送信」を設定 → Gmailから `info@…` 名義で送信できる
4. Claude Codeからは **Gmail API**(OAuthを一度設定すれば読み書き両方可)をPythonスクリプトで叩く
   - 受信箱のチェック、内容の要約、返信ドラフトの作成・送信まで自動化可能

### この構成の副次的な価値

Claude Codeのスケジュール実行(cron)と組み合わせると、
「1時間ごとに受信箱をチェック → 問い合わせが来ていたら内容を読んで返信案を作成 → 通知」
という、**まさに自分が売ろうとしている受付AIそのもの**が自前で動く。
営業の場で「私自身の問い合わせ対応はAIがやっています」と言えるのは強い。

## 代替案

| 手段 | 用途 | メモ |
|---|---|---|
| Google Workspace https://workspace.google.com/intl/ja/ | 独自ドメインメールの正攻法 | 月800円前後。転送設定不要で信頼性が高い |
| Resend https://resend.com/ | メール送信API | 無料枠 月3,000通。問い合わせフォームの通知送信向き。受信箱の管理には不向き |

## 注意点(必ず守る)

- **API認証はユーザー自身の手で設定する。** OAuthの初回設定やアプリパスワードの発行はユーザーが行い、認証情報はClaudeが直接扱わない。環境変数などに置いてスクリプトから読む形にする。
- **自動送信はしない。** 最低限、最初は「Claudeがドラフト → ユーザーが承認 → 送信」の運用にする。医療機関相手の返信を無確認で自動送信するのは事故のもと。Claudeが代理で送る場面でも都度確認を挟む。

## 着手順

ドメイン取得 → メール開通 → Gmail APIのOAuth設定 → 監視スクリプト作成。
ドメイン取得とサイト公開(Cloudflare Pages)は同じCloudflareでまとめて済ませられるのでセットで行うのが効率的。
